Dostaffkin — продолжение исходного проекта (урок 3)

Главная страница index.html сохранена из предыдущей версии сайта.
К ней добавлены страницы оформления доставки и отслеживания по макету maket.pdf.

Страницы:
index.html — исходная главная страница Dostaffkin;
order.html — оформление доставки;
track.html — отслеживание посылки.

Папки:
fonts/ — локальные шрифты;
images/ — исходные изображения главной страницы и новые материалы урока;
styles/ — исходные стили главной страницы и стили новых страниц.

Запуск:
1. Распакуйте архив.
2. Откройте папку DELIVERY в VS Code.
3. Запустите index.html через Live Server.
4. На главной нажмите «Оформить доставку» или «Отследить посылку».

Примечание: расчёт и отслеживание демонстрационные, реальная служба доставки не подключена.
